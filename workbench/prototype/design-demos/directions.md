# AICA 工作台 v0.2 三方向门 · spec + 方向卡

## 共享 spec（三版同内容，只换设计）

**产品**：AICA 工作台——本地 agent 运行时（`agent:local`）的任务驾驶舱。Windows 桌面单窗口。
**受众**：系统所有者本人（开发者），长时间盯屏使用。
**内容**（三版都必须呈现，mock 数据）：
- 收件箱「需要你」：4–6 张可裁决卡——危险 gate（删除确认，err 级）、问询 gate（快速选项）、待验收产物卡（含条款负载"条款 3/5 · 含源码引用"）、深层 gate（面包屑 `调研各家 Agent 界面 › 调研 Claude Desktop › 抓取 openclaudeui token 值`）
- 正在运行带：3 张紧凑实时卡（呼吸点、subject、实时片段、耗时）
- 任务视图（点进运行卡）：根卡（serif 标题 + `accept` 五条验收芯片：verified/pending/human-needed/failed + 「验收标准 +2 项」增量徽标）→ 事实卡行（子节点结论+溯源）→ 产物行（md 卡 / diff 卡 +N−N / page 卡迷你网页预览）→ 缩进任务树（L2 全行 / L3 紧凑 / L4+ 聚合片，`waits_on` 徽章 `person:answer`/`dependency`/`queued`，祖先徽标上卷 `1 待处理`）→ 「过程与证据 ▸」折叠流
- 左轨：nav（需要你[角标]/运行中/任务库/项目·场景/系统态）+ daemon●/server●
- composer：悬浮圆角大卡 + 拨盘排（模式/权限/模型/effort）
**情感基调**：克制、可信、有工艺感；用户原话批评 v4「太丑也没有重心」「人文主义不足」——本题的题眼是**重心与人味**。
**格式**：单文件 HTML，1440×900 桌面，file:// 可开，内联全部 CSS/JS，零依赖。
**硬底线**：正文 ≥14px、标签 ≥12px、对比度 ≥4.5:1、可点 ≥44px。

## 选定三版

- **dir-1 = Rauno 精工暗舱**（候选1）：暗暖工艺、机械感微交互——「重心」由物理质感给出
- **dir-2 = 书卷工作志**（候选2）：浅纸衬线、版心呼吸——「人文主义」正面回答
- **dir-3 = Swiss 黑白网格**（候选5）：零彩色纪律、Geist 锐角——冷静对照组，若它反而最"高级"说明彩色本身就是干扰

备选：Linear（候选3，与 dir-1 同属暗色家族让位）、Raycast（候选4）、节气色谱（候选6）。
